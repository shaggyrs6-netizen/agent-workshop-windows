# Agent Workshop for Windows 11

Public preview edition of the Agent Workshop theme, prepared by Lee Shand / Wired Differently.

## Download and try

Open [the test release](https://github.com/shaggyrs6-netizen/agent-workshop-windows/releases/tag/v0.1.0-preview.2) and download **Agent-Workshop-Windows-11-0.1.0-preview.2.zip** from Assets. No GitHub account or separate wallpaper download is needed.

1. Extract the ZIP on Windows 11.
2. Read START-HERE.txt and save your existing Windows theme.
3. Double-click the Standard-16x9 or Ultrawide .deskthemepack.

Five wallpapers, a 30-minute shuffled slideshow, requested dark appearance and violet accent, plus optional Windows Terminal colours. Standard 16:9 images preserve the whole scene with a graphite surround. Full installation, manual colour fallback, testing and restore instructions are in [START-HERE.txt](START-HERE.txt).

## All wallpapers included

The ZIP contains all five pictures as ordinary JPEGs in **Wallpapers/Standard-16x9** and **Wallpapers/Ultrawide**, as well as inside the two theme packs. There is no dependency on Omarchy or its wallpaper repository. Right-click a JPEG to set it as your background, or follow START-HERE for a manual slideshow.

## Test status

Archive extraction, file hashes, image decoding and dimensions, theme references and Terminal JSON were checked on Linux. **Windows 11 import and appearance have not yet been tested.** This remains a preview awaiting Windows runtime testing.

Report whether import works, all five images appear, dark mode/accent apply, the Terminal scheme loads and the previous theme restores. Include the Windows version if something fails.
